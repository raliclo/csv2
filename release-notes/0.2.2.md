**What changed since v0.2.1**

- **Windows needs no Swift any more (SR).** `csv2.exe` links the Swift runtime and Foundation statically, and its archive carries the Microsoft VC++ runtime DLLs it imports (`vcruntime140.dll`, `msvcp140.dll`, and on x86_64 `vcruntime140_1.dll`) beside it. The packaging script runs the extracted copy with only `C:\Windows\System32` and `C:\Windows` on `PATH` to prove it. Up to v0.2.1 the Windows build loaded the Swift runtime of the exact version that built it from `PATH`; upgrading Swift from 6.4.1 to 6.4.2 deleted the old runtime, and the installed csv2 stopped working in every shell opened before the upgrade. Keep the DLLs in the same directory as `csv2.exe`. The price is size: `csv2.exe` is about 53 MB instead of 0.7 MB, the archive about 15 MB.
- If you installed the Swift runtime only for csv2, you can remove it after upgrading.

**v0.2.1 之後的改變**

- **Windows 不再需要 Swift（SR）。** `csv2.exe` 把 Swift runtime 與 Foundation 靜態連結進去，封存裡也在它旁邊附上它匯入的 Microsoft VC++ runtime DLL（`vcruntime140.dll`、`msvcp140.dll`，x86_64 另有 `vcruntime140_1.dll`）。打包腳本會在 `PATH` 只有 `C:\Windows\System32` 與 `C:\Windows` 的情況下執行解開後的那一份來證明這一點。到 v0.2.1 為止，Windows 版會從 `PATH` 載入「建置它的那一版」Swift runtime；把 Swift 從 6.4.1 升到 6.4.2 時舊的 runtime 被刪掉，在升級之前開啟的每一個 shell 裡，已安裝的 csv2 都無法執行。請讓那些 DLL 與 `csv2.exe` 放在同一個目錄。代價是大小：`csv2.exe` 約 53 MB，原本約 0.7 MB；封存約 15 MB。
- 如果你當初只是為了 csv2 才安裝 Swift runtime，升級之後可以移除它。
